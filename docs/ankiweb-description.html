Prisma makes reading cards more active, on any note type you choose, without touching your templates. Features
  • 🌈 Color gradient (BeeLine) — every line fades into the next color, guiding your eye across line breaks. Readable in light and dark themes.
  • 🅱 Bionic reading — the start of each word is bold.
  • 🔀 Random layout — width, alignment, spacing and font size change on every showing, so you memorize content, not the card's shape.
  • 🔊 Read aloud — speech synthesis with adjustable speed (0.5× to 2×), pitch, language and voice.
  • 🎤 Spoken-word highlight — karaoke style.
  • 👁 Progressive reveal — words appear in time with the speech.
Two ways to apply it
  • Runtime (default): the add-on injects the features while a card is shown. Desktop only, templates untouched.
  • Baked: tick "Bake (mobile)" for a note type and the preset is written into its templates, so the same features run on AnkiDroid and AnkiMobile after a sync. Refreshed on every save, removed cleanly when unticked.
Setup
  1. Install, restart Anki.
  2. Tools → Prisma… → tab Note types → tick the note types to apply it to (none are enabled by default).
  3. Optional: set global defaults, or override any feature per note type (Global / On / Off).
Toggle everything on or off during review with Ctrl+Shift+L (configurable). Notes
  • Hidden text, scripts, input fields and hand-colored words are left alone.
  • Speech depends on the voices installed on your system; on mobile, iOS may need a tap before speech starts.
  • On heavily structured templates, turn Random layout off for that note type.
Tested on Anki 25.02. Source, issues and video: github.com/drgmb/prisma-anki by drgmb
